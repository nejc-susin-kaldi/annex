# Goat Arcade data dictionary

Generated by `scripts/democlient.sh dictionary` from the comments on the gateway views
(`db/product/clientlink/api_views_arcade.sql`); edit those, not this file. All data is synthetic.
The same descriptions are in the gateway's OpenAPI document (`GET $ANNEX_GATEWAY_URL/` with your app's token).

## `venues`
The open arcades (venues), with their opening hours and how many machines stand there now.

| Column | Type | Meaning |
|---|---|---|
| `venue_code` | text | Short venue code, e.g. LJ1. Other views refer to venues by it. |
| `venue_name` | text | Venue name, e.g. Goat Arcade Metelkova. |
| `city` | text | City. |
| `country` | character(2) | Country, ISO 3166 two-letter code (SI, HR, AT, IT). |
| `lat` | numeric(8,5) | Latitude (WGS 84), for maps. |
| `lon` | numeric(8,5) | Longitude (WGS 84), for maps. |
| `opened_on` | date | The day the venue opened. |
| `opening_hours` | jsonb | JSON object by weekday (mon..sun): ["16:00", "24:00"] or null when closed. A closing time earlier than the opening time is after midnight. |
| `machines` | bigint | Machines on the floor now (pinball, video and other). |
| `pinball_machines` | bigint | Pinball machines on the floor now. |

## `machine_models`
The catalogue of machine models (titles): pinball tables by era, plus video cabinets and other games. All titles and makers are fictional.

| Column | Type | Meaning |
|---|---|---|
| `model_id` | integer | Model id. |
| `title` | text | Title of the game, e.g. Haunted Lighthouse. |
| `manufacturer` | text | Manufacturer. |
| `manufacturer_country` | character(2) | Manufacturer's country, ISO two-letter code. |
| `release_year` | integer | Year the model came out. |
| `era` | text | Pinball era: EM (electro-mechanical, to 1977), SS (solid state, 1978-1990), DMD (dot-matrix display, 1991-2012), LCD (2013 on). NULL for video and other machines. |
| `era_name` | text | The era spelled out. |
| `machine_type` | text | pinball, video (arcade video cabinet) or other (air hockey, claw, roll-a-ball). |
| `theme` | text | What the game is about. |
| `designer` | text | Designer (fictional). |
| `flippers` | smallint | Number of flippers (pinball only). |
| `max_multiball` | smallint | Most balls in play at once (pinball only). |
| `ramps` | integer | Number of ramps (pinball only). |
| `modes` | integer | Number of game modes in the rules (pinball only). |
| `toys` | text[] | Toys and mechanisms on the playfield; for video and other machines, the controls. |
| `cabinets_on_floor` | bigint | How many machines of this model stand in venues now. |

## `machine_floor`
Every machine on a venue floor now, with its recent play and service state. One row per physical machine (cabinet).

| Column | Type | Meaning |
|---|---|---|
| `machine_id` | integer | Machine id (one physical cabinet). Other views refer to machines by it. |
| `serial_no` | text | Manufacturer serial number. |
| `venue_code` | text | Where it stands (venues.venue_code). |
| `venue_name` | text | Venue name. |
| `city` | text | Venue city. |
| `model_id` | integer | Model (machine_models.model_id). |
| `title` | text | Title of the game. |
| `manufacturer` | text | Manufacturer. |
| `release_year` | integer | Year the model came out. |
| `era` | text | Pinball era (EM, SS, DMD, LCD); NULL for video and other. |
| `machine_type` | text | pinball, video or other. |
| `condition` | text | Condition as last recorded: excellent, good, fair or needs work. |
| `price_per_play_eur` | numeric | Price of one credit (one game) in EUR. |
| `installed_on` | date | When the machine was installed (at its first venue). |
| `games_7d` | bigint | Games played on it in the last 7 days. |
| `games_30d` | bigint | Games played on it in the last 30 days. |
| `last_played_at` | timestamp with time zone | Start of the last game in the last 30 days (NULL if none). |
| `open_ticket` | boolean | True if a service ticket for it is still open. |
| `out_of_order` | boolean | True if an open ticket took it off the floor: nobody can play it now. |
| `last_service_at` | timestamp with time zone | When its last service ticket was opened. |

## `leaderboard`
The top 10 scores of all time on every pinball and video model, by members (anonymous games have no name). One row per member and model: their best game. Ties share a rank.

| Column | Type | Meaning |
|---|---|---|
| `model_id` | integer | Model (machine_models.model_id). |
| `title` | text | Title of the game. |
| `rank` | bigint | Place, 1 to 10. |
| `handle` | character(3) | Three-letter initials, as shown on a machine's high-score table. Not unique. |
| `nickname` | text | The member's public nickname. Unique. |
| `score` | bigint | Score. Scales differ a lot by era: compare scores only within one model. |
| `venue_code` | text | Venue where the score was set. |
| `played_at` | timestamp with time zone | When the game started. |
| `machine_id` | integer | The machine it was played on. |

## `player_profiles`
Members (players with a member card), public profile only: no names or contact details.

| Column | Type | Meaning |
|---|---|---|
| `player_id` | integer | Member id. |
| `handle` | character(3) | Three-letter initials. Not unique. |
| `nickname` | text | Public nickname. Unique; leaderboard and tournament views use it. |
| `home_venue_code` | text | The venue where they signed up. |
| `member_since` | date | Sign-up day. |
| `rating` | integer | Skill rating, about 800 to 2400 (league play; higher is better). |
| `games_180d` | bigint | Games played with their card in the data (the last 180 days). |
| `venues_played` | bigint | How many venues they played at. |
| `last_played_at` | timestamp with time zone | Start of their last game. |
| `leaderboard_spots` | bigint | On how many models they are in the top 10. |
| `best_rank` | bigint | Their best place on any leaderboard (1 = holds a top score). |

## `daily_plays`
Play per machine per day: games, credits, estimated revenue, tilts. One row per day, venue and machine with at least one game. Days are local (Central European) dates.

| Column | Type | Meaning |
|---|---|---|
| `day` | date | Local date. |
| `venue_code` | text | Venue where the machine stood that day. |
| `machine_id` | integer | Machine (machine_floor.machine_id). |
| `title` | text | Title of the game. |
| `era` | text | Pinball era; NULL for video and other. |
| `machine_type` | text | pinball, video or other. |
| `games` | bigint | Games played. |
| `credits` | bigint | Credits used (a game is one credit, sometimes two). |
| `revenue_eur` | numeric | Credits times the machine's current price, in EUR. The counted cash is in revenue_weekly. |
| `avg_duration_s` | numeric | Average game length in seconds. |
| `tilts` | bigint | Games that ended in a tilt (the player shook the machine too hard). |
| `members` | bigint | Distinct members who played (anonymous games not counted). |

## `machine_events_daily`
What the machines reported, per machine, day and event type. Faults hint at a machine that needs a technician.

| Column | Type | Meaning |
|---|---|---|
| `day` | date | Local date. |
| `machine_id` | integer | Machine (machine_floor.machine_id). |
| `title` | text | Title of the game. |
| `current_venue_code` | text | Where the machine stands now (NULL: in storage). |
| `event_type` | text | tilt, slam_tilt (a hard tilt), ball_search (the machine lost track of a ball), coil_fault, switch_fault, jackpot, replay (a free game won by score), match (a free game won by lottery at the end). |
| `events` | bigint | How many. |

| `parts` | text | Parts used, e.g. "flipper rebuild kit, coil sleeve x2"; NULL if none. |
